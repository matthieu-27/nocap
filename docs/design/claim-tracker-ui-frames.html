Design frames · phase 3 · frontend

NoCaP — UI frames

Six screens for the claim forum, drawn with the shadcn/ui component vocabulary (Tailwind v4, new-york style). Every region maps to a real shadcn component or block — the mapping strip under each frame is the build list.

Colors are the real tweakcn export pasted into this file verbatim — this page previews apps/web/app/styles.css as it will ship. Swap the export, the frames re-skin; the markup doesn't change.

Voting is single-axis and semantic: ▲ answers “yes, well-sourced”, ▼ answers “no, poorly sourced” — never agreement. Vote colors sit outside the theme on purpose.
